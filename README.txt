Digonto Studio
==============
The one Digonto icon on your desktop. It shows every Digonto program as a tile; click a tile and that program opens
in its own window (its own menu, its own icon). Right side: recent files. "Open file ..." picks the right program
by file type. Exit closes only Studio; open programs keep running.

Keep a program in the Dock / taskbar: open it, right-click its icon there, "Keep in Dock" / "Pin to taskbar" /
"Add to favorites". macOS: the programs are in the Applications folder, drag one to the Dock.

Removing programs
-----------------
Every Digonto program is listed in your system's own app list, so you can remove a single one there:
Windows: Settings > Apps > Installed apps > Digonto ... > Uninstall.
Linux: right-click the program in the app menu > "Uninstall ...", or the Uninstall button on its tile in Studio.
macOS: the Uninstall button on its tile in Studio (dragging the .app to the Trash removes only the launcher;
"uninstall-macos.command" removes everything).
Uninstalling Digonto Studio removes ALL Digonto programs. Your own files are never touched.
